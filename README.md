# 🤖 ربات تلگرامی هوشمند با هوش مصنوعی جمینای (Cloudflare Workers)

این پروژه یک ربات تلگرامی هوشمند و بسیار سبک است که روی **Cloudflare Workers** اجرا می‌شود و از هوش مصنوعی **Gemini** برای پاسخگویی استفاده می‌کند. تمامی تنظیمات ربات از طریق یک پنل مدیریت شیشه‌ای (Inline Keyboard) درون خود تلگرام انجام می‌شود و نیازی به تغییر کد برای شخصی‌سازی نیست.

## ✨ امکانات
- 🧠 **هوش مصنوعی جمینای:** پاسخگویی هوشمند با استفاده از مدل سبک و سریع Gemini Flash-Lite.
- 📝 **تغییر نام ربات:** امکان تنظیم نام ربات مستقیماً از داخل پنل مدیریت.
- 🎭 **شخصیت‌پردازی (Mood):** قابلیت تغییر لحن ربات (خوشحال، عصبانی، لاتی، لوس و معمولی).
- 👥 **مدیریت گروه‌ها:** شناسایی خودکار گروه‌های جدید و امکان فعال/غیرفعال کردن ربات در هر گروه با تایید ادمین.
- ⚡️ **پاسخ‌های سریع (Quick Replies):** افزودن، ویرایش و حذف پاسخ‌های از پیش تعیین شده برای کلمات خاص.
- 💾 **ذخیره‌سازی دائمی (KV):** ذخیره تمامی تنظیمات با استفاده از Cloudflare KV (تنظیمات با ری‌استارت پاک نمی‌شوند).

## 🚀 آموزش راه‌اندازی در Cloudflare Workers

### پیش‌نیازها
۱. توکن ربات تلگرام (دریافت از [@BotFather](https://t.me/BotFather))
۲. کلید API جمینای (دریافت از [Google AI Studio](https://aistudio.google.com/))
۳. آیدی عددی تلگرام ادمین (دریافت از ربات‌هایی مثل `@userinfobot`)
۴. یک اکانت رایگان در [Cloudflare](https://dash.cloudflare.com/)

### مراحل نصب
۱. وارد داشبورد کلودفلر شوید و از بخش **Workers & Pages** یک Worker جدید بسازید.
۲. به بخش **Settings -> Variables and Secrets** بروید و متغیرهای محیطی زیر را اضافه کنید:
   - `BOT_TOKEN`: توکن ربات تلگرام شما
   - `GEMINI_API_KEY`: کلید ای‌پی‌آی گوگل جمینای
   - `ADMIN_ID`: آیدی عددی تلگرام شما
۳. وارد تب **KV Namespace Bindings** (در بخش Bindings) شوید. یک KV جدید (مثلاً با نام `BOT_DB`) بسازید و آن را دقیقاً با نام متغیر `DB` متصل کنید.
۴. روی دکمه **Edit Code** کلیک کنید، کدهای پیش‌فرض را پاک کرده، کدهای این ریپازیتوری (فایل `worker.js`) را جایگذاری کنید و دکمه **Deploy** را بزنید.
۵. **تنظیم وب‌هوک:** آدرس Worker خود را همراه با توکن ربات در لینک زیر جایگذاری کرده و آن را در مرورگر باز کنید تا تلگرام پیام‌ها را به سرور شما بفرستد:
   `https://api.telegram.org/bot<YOUR_BOT_TOKEN>/setWebhook?url=<YOUR_WORKER_URL>`

## 🎮 راهنمای استفاده ادمین
در ربات خود دستور `/admin` را ارسال کنید تا پنل مدیریت شیشه‌ای باز شود. سپس می‌توانید تمام بخش‌ها (اسم، لحن، پاسخ‌های سریع و گروه‌ها) را در همان یک پیام و به صورت گرافیکی مدیریت کنید.
