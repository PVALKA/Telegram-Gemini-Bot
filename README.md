# 🤖 Telegram-Gemini-Bot

**یک ربات تلگرامی باحال مخصوص سرگرمی با هوش مصنوعی جمینای (Cloudflare Workers)**

این پروژه یک ربات تلگرامی هوشمند و بسیار سبک است که روی **Cloudflare Workers** اجرا می‌شود و از هوش مصنوعی **Gemini** برای پاسخگویی استفاده می‌کند. تمامی تنظیمات ربات از طریق یک پنل مدیریت شیشه‌ای (Inline Keyboard) درون خود تلگرام انجام می‌شود و نیازی به تغییر کد برای شخصی‌سازی نیست.

---

## ✨ امکانات
- 🧠 **هوش مصنوعی جمینای:** پاسخگویی هوشمند با استفاده از مدل سبک و سریع Gemini Flash-Lite.
- 📝 **تغییر نام ربات:** امکان تنظیم نام ربات مستقیماً از داخل پنل مدیریت.
- 🎭 **شخصیت‌پردازی (Mood):** قابلیت تغییر لحن ربات (خوشحال، عصبانی، لاتی، لوس و معمولی).
- 👥 **مدیریت گروه‌ها:** شناسایی خودکار گروه‌های جدید و امکان فعال/غیرفعال کردن ربات در هر گروه با تایید ادمین.
- ⚡️ **پاسخ‌های سریع (Quick Replies):** افزودن، ویرایش و حذف پاسخ‌های از پیش تعیین شده برای کلمات خاص.
- 💾 **ذخیره‌سازی دائمی (KV):** ذخیره تمامی تنظیمات با استفاده از Cloudflare KV (تنظیمات با ری‌استارت پاک نمی‌شوند).

---

## 🚀 آموزش راه‌اندازی در Cloudflare Workers

### 📌 پیش‌نیازها
1. توکن ربات تلگرام (دریافت از [@BotFather](https://t.me/BotFather))
2. کلید API جمینای (دریافت از [Google AI Studio](https://aistudio.google.com/))
3. آیدی عددی تلگرام ادمین (دریافت از ربات‌هایی مثل `@userinfobot`)
4. یک اکانت رایگان در [Cloudflare](https://dash.cloudflare.com/)

### 🛠 مراحل نصب
1. وارد داشبورد کلودفلر شوید و از بخش **Workers & Pages** یک Worker جدید بسازید.
2. به بخش **Settings -> Variables and Secrets** بروید و متغیرهای محیطی زیر را اضافه کنید:
   - `BOT_TOKEN`: توکن ربات تلگرام شما
   - `GEMINI_API_KEY`: کلید ای‌پی‌آی گوگل جمینای
   - `ADMIN_ID`: آیدی عددی تلگرام شما
3. وارد تب **KV Namespace Bindings** (در بخش Bindings) شوید. یک KV جدید (مثلاً با نام `BOT_DB`) بسازید و آن را دقیقاً با نام متغیر `DB` متصل کنید.
4. روی دکمه **Edit Code** کلیک کنید، کدهای پیش‌فرض را پاک کرده، کدهای این ریپازیتوری (فایل `worker.js`) را جایگذاری کنید و دکمه **Deploy** را بزنید.
